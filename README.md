# Projekt inżynierski: *Rozpoznawanie instrumentów muzycznych w utworach polifonicznych za pomocą sieci neuronowej*

### PL

Celem projektu jest implementacja i ocena skuteczności konwolucyjnej sieci neuronowej (CNN) w rozpoznawaniu instrumentów muzycznych w nagraniach polifonicznych.

W projekcie wykorzystujemy krótkoczasową transformatę Fouriera (STFT) oraz mel-spektrogramy jako reprezentację sygnału audio, na podstawie której model będzie przewidywał obecność poszczególnych instrumentów.

Status projektu: W trakcie realizacji. 

Zbiór danych wykorzystany w projekcie: [Slakh](http://www.slakh.com/)

### ENG

The aim of this project is to implement and evaluate the performance of a convolutional neural network (CNN) for musical instrument recognition in polyphonic audio recordings.

The project uses the Short-Time Fourier Transform (STFT) and mel-spectrograms as an audio signal representation. Based on these representations, the model will predict the presence of individual musical instruments.

Project status: In progress.

Dataset used is the project: [Slakh](http://www.slakh.com/)
